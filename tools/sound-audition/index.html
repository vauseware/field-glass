Battle sound: synth audition

Eleven sounds built from Web Audio nodes, with no files. Each is meant to be heard from far off, the way the replay hears a fight across the field. Each card comes with freesound recordings of the same thing. Play both, then run the blind test. Then tick every source you want in that sound's pool, synth and recordings together.

Synth and recording are levelled to the same RMS and cut to the same length, so judge the timbre. Use headphones or monitors. Observer distance, on by default, plays everything as the viewer above the map would hear it: highs rolled off at 1.4 kHz and a long field reverb. Turn it off to hear the raw recording. Re-roll builds a new take from fresh random values. Hear the mix plays the pool the way the replay would: random picks, never the same one twice running, each shifted up to 5% in rate and 2 dB in level. The wind and rumble beds layer their pool instead.
